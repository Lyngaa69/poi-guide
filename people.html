People

Invite people to routes. Everyone gets a personal link. If you remove someone, their link stops working. The names are kept in a private repository, never on the public site.

GitHub is not connected on this device. Open Routes, open any route, and fill in “GitHub connection” under step 3. Then come back here.

Set up the private list

The list of people must be kept in a private repository, separate from the public site. You only do this once.

  1. On GitHub, create a new repository. Name it for example poi-guide-admin. Choose Private and tick Add a README file.
  2. Let the Studio token reach it: GitHub > Settings > Developer settings > Fine-grained tokens > your token > Edit. Under “Repository access” add the new repository. Keep Contents: Read and write. Save.
  3. Write the name here and press Check.
