1. Place the stops

A stop is read out when you drive within the trigger radius of it. Snapping puts the stop on the road so it is always triggered. For a place away from the road, snap a stop onto the nearest point of the route and say in the text where the place is.

2. Write the texts

Leave a text empty if you want Claude to write it later. Wayside then only reads out the name.

With the Gemini voice you can add expressions such as <breath> or <chuckle> where the cursor is: pick one under a text and press Insert. The phone voice and the Listen button skip them.

3. Turn directions

With directions switched on, Wayside shows an arrow and says “In 300 metres, turn right” along the route. The turns below are worked out from the shape of the track, because Wayside has no road map. Check them, and correct what is wrong. Wayside follows the route as planned and does not find another way.

4. Publish to Wayside

The default radius is used by every stop that is set to “Route default” in step 2.

This route has recorded audio. Stops you change use the phone voice until new audio has been made. If automatic audio is set up, new audio appears a few minutes after you publish. If not, send the GPX to Claude.

GitHub connection: not set up

Studio saves the route straight into your repository, so you do not have to upload files by hand. This needs a token. It is stored only in this browser and is never sent anywhere except to GitHub.

How to create the token (once)

  1. On github.com, click your profile picture, then Settings, then Developer settings at the bottom of the menu.
  2. Choose Personal access tokens > Fine-grained tokens > Generate new token.
  3. Name it Wayside Studio and pick an expiry date, for example 90 days.
  4. Under Repository access choose Only select repositories and pick your Wayside repository.
  5. Under Permissions open Repository permissions and set Contents to Read and write.
  6. Click Generate token, copy it, and paste it above. Do not share it with anyone, not even in a chat.

Menu names on GitHub may differ a little. If your phone is lost, delete the token under the same settings.
